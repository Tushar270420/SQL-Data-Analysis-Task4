# Task 3: SQL for Data Analysis

This project contains SQL queries written for a sample eCommerce dataset to demonstrate data analysis skills using SQL.

## Queries Included:
- SELECT, WHERE, ORDER BY
- GROUP BY with SUM
- JOINS and Subqueries
- Views and Indexes

## Tool Used:
- DB Fiddle (MySQL 8.0)

## Files:
- queries.sql (contains all SQL code)
- screenshots/ (output of each query)
